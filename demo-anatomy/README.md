# 人体解剖 3D 演示（demo-anatomy）

为 health-monitor **V0.3 人体大屏** 做的预研演示。基于
[vastlabs/human-atlas](https://github.com/vastlabs/human-atlas) 开放人体解剖数据，
用 Three.js 在浏览器本地渲染完整人体网格，无外部 CDN、无后端依赖，纯静态可独立部署。

## 运行

需要任意 HTTP 静态服务（ES Module 不允许 `file://` 直开）。项目根目录下：

```bash
python -m http.server 8021
```

浏览器访问 <http://127.0.0.1:8021/demo-anatomy/>。

## 操作

| 操作 | 效果 |
|------|------|
| 左键拖拽 | 旋转视角（带阻尼） |
| 滚轮 | 缩放（0.2 ~ 3.5） |
| 右键拖拽 | 平移视角 |
| 左侧 15 个系统开关 | 显示/隐藏对应系统（骨骼、肌肉、心脏、动脉、静脉、神经、呼吸、消化、泌尿、淋巴、内分泌、生殖、体表、结缔、感官） |
| 顶部下拉框 | 快捷定位器官并聚焦（心脏、肝脏、双肾、胰腺等健康监控相关器官） |
| 点击模型部件 | 右侧详情面板显示部件名称与所属系统 |
| 点击异常部位/标注点 | 弹出异常详情：等级、异常指标、检查记录（时间轴）、健康建议 |
| 点击环形图图例 | 3D 视角聚焦对应等级的第一个异常部位 |

## 异常部位叠加（demo 数据）

- 5 个异常部位（心脏·严重、肝脏·中度、左肾·中度、右肺·轻度、胃·轻度）以**脉冲发光 + 头顶标注点**闪烁展示
- 左上角统计面板：SVG 环形图展示严重程度占比（图例可点击定位），下方红/橙/黄分级数字卡片
- 点击异常部位或标注点，右侧面板显示异常指标、检查记录（竖向时间轴，默认最近 3 条可展开全部）与综合建议
- 数据为内置模拟（`app.js` 中 `ABNORMALITIES` 常量），结构即未来后端 `/api/abnormalities` 返回格式，接入真实数据时替换即可

## 目录

| 路径 | 说明 |
|------|------|
| `index.html` | 页面纯标记（内联 importmap 映射 three） |
| `css/style.css` | 全站样式 |
| `js/app.js` | 场景构建、系统合并渲染、拾取、侧栏/下拉/详情逻辑 |
| `models/` | `atlas.json` 解剖树 + `body-*.bin.gz` 压缩网格数据 |
| `vendor/` | 本地第三方库：`three.module.min.js`、`OrbitControls.js` |
| `importmap.json` | 早期遗留的外部 importmap 写法，已内联到 HTML，仅作参考 |
| `ATTRIBUTION.md` / `LICENSE` | 模型数据来源与许可（CC BY 4.0） |
