# 错误码规范：健康数据监控（health-monitor）

接口约定：
- 成功：`{code: 0, data, message}`
- 失败：HTTPException + `{"detail": {"code": <错误码>, "message": ...}}` + 对应状态码

## 错误码表
| 错误码 | 含义 | HTTP 状态 | 典型场景 |
|--------|------|-----------|---------|
| 1001 | 未登录/会话过期/口令错误 | 401 | 登录失败、会话过期 |
| 1002 | 参数/业务校验失败 | 400 | 未选择图片、超数量、模型不存在、备份文件名不合法 |
| 1006 | 模型端点非法/重复 | 400 | API 地址格式错误、同名同端点重复添加 |
| 1007 | 备份包校验失败 | 400 | 非本应用包、路径穿越、体积超限 |
| 1008 | 备份/还原进行中 | 409 | 同一时刻重复操作 |
| 2004 | 资源不存在 | 404 | 体检记录/指标/身体数据/自定义模型不存在 |
| 2005 | 备份文件不存在 | 404 | 下载/删除/还原不存在的备份 |
| 3004 | 备份/还原执行失败 | 500 | 文件系统错误（数据已回滚保护） |
| 3005 | 重启脚本缺失/失败 | 500 | manage.sh 不存在或调用失败 |
| 413 | 请求体过大 | 413 | Content-Length 超 60MB（中间件直接返回纯文本） |
| 403 | 跨域写请求 | 403 | Origin 与 Host 不一致（中间件直接返回纯文本） |

## 约定
- 错误响应统一为 `{"detail": {"code": ..., "message": ...}}`，可附加 `data` 字段携带上下文（如 `{"id": 42}`）
- 不区分「模型名错误」与「端点不存在」的细节，统一 1002 文案防探测
- 前端统一在 `api()` 封装中读取 `detail.message` 提示用户
- 错误码表仅保留本项目的通用/复用码（1001/1002/1006/1007/1008/2004/2005/3004/3005）
