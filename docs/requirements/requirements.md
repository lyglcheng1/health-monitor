# 需求文档：健康数据监控（health-monitor）

## 1. 项目背景与目标

个人身体健康数据监控系统。用户的历史体检报告、医院检查病历、化验单、体重等
多为**纸质/图片扫描件**，散落在各处，无法统一查看、追溯变化、发现问题。

目标：
1. 集中存储：图片原件 + 本地 OCR 文本 + 结构化指标，全部保存在本机；
2. AI 辅助：基于 OCR 文本用 LLM 自动提取指标、聚合分析给出健康建议；
3. 可视化大屏：3D 人体模型展示问题部位（异常指标高亮标注）。

## 2. 部署形态与数据边界（非功能需求）

| 项 | 决策 |
|----|------|
| 部署 | 局域网单机（Ubuntu 服务器 10.10.10.88，端口 **8020**） |
| 数据 | 全部本地：SQLite（`data/health.db`）+ 图片原件（`data/uploads/`）+ 备份（`data/backups/`） |
| OCR | **本地 RapidOCR**（onnxruntime），图片不出本机 |
| AI | 可选接 LLM（OpenAI 兼容 / Anthropic 端点），需自备 Key 在「模型设置」页添加自定义模型；**不配置也能用**（OCR + 手工指标） |
| 登录 | 可选：.env 配 `AUTH_PASSWORD` 即开启 |
| 技术栈 | 冻结：Python 3.10+ / FastAPI 0.104.x / SQLAlchemy 2.0（异步）/ SQLite / RapidOCR / Three.js（后续）/ ECharts（后续） |

## 4. 功能需求

### 登录（V0.1 已实现）
- F-101：配置 `AUTH_PASSWORD` 后，未登录访问 API 返回 401 JSON，访问页面 302 到 /login
- F-102：登录签发 HttpOnly + SameSite=Lax 签名 cookie，有效期 `SESSION_TTL_HOURS`（默认 7 天）
- F-103：统一文案「用户名或密码错误」，防账号枚举

### 体检记录（V0.1 已实现）
- F-201：批量上传图片（≤10 张/批，单张 ≤20MB），每张 = 一条体检记录；可选日期/医院/备注
- F-202：上传后本地 OCR，识别文本存入 `ocr_text`，页面可预览/编辑
- F-203：体检列表按日期倒序，显示记录数/指标数/来源
- F-204：体检详情：原始图片、OCR 文本、基本信息（日期/医院/来源/附件/备注）可编辑
- F-205：指标手工录入：名称/数值/单位/参考下限/上限/异常标记/身体部位/备注
- F-206：删除体检记录 → 级联删除指标 + 删除图片目录
- F-207：体检记录含「来源/附件」字段：上传时默认取原始文件名，列表与详情展示，可修改

### 日常身体数据（V0.1 已实现）
- F-301：按日期录入体重/血压/血糖等（类型可自由选择/填写）
- F-302：列表倒序、删除单条

### 模型管理（V0.1 已实现）
- F-401：页面自定义模型（OpenAI 兼容 / Anthropic 端点、Key 入库不回显），无内置 .env 清单
- F-402：启用/停用互斥（全表至多一行 enabled=1），路由值 `{name}@{id}` 区分同名多行
- F-403：连通测试与添加表单「测试协议」探测（诊断语义，恒 200）

### 备份还原（V0.1 已实现）
- F-501：一键备份（数据库在线快照 + uploads 原件 + manifest），支持清单/下载/删除/上传还原
- F-502：还原前自动生成 safety 快照；旧库改名留底 `data/restore_<ts>.db`

### AI 提取（V0.2 规划，已确认：手动触发）
- F-601：详情页「AI 提取」按钮 → 把 `ocr_text` 发给 LLM → 返回结构化指标 JSON → 以草稿形式展示，用户确认后批量入库
- F-602：提取失败可重试；未配置 LLM 时提示去模型设置配置
- F-603：提取结果与手工录入一致（同表 metrics），可继续编辑

### AI 分析（V0.2 规划，已确认：结果保存历史）
- F-604：选择时间范围 → 汇总异常指标 + 趋势 → LLM 生成健康建议（中文、引用具体指标值）
- F-605：分析结果**入库保存**（新增 `analyses` 表：时间范围/输入摘要/建议全文），可回看历史分析列表

### 3D 人体大屏（V0.3 已实现，F-705 待办）
- F-701：✅ 独立页面（`#/body3d`），Three.js 渲染人体模型（复用 demo-anatomy）
- F-702：✅ **默认只高亮异常**（严重/中度/轻度），可**切换查看全部指标**的部位分布；正常/异常按**最近一次体检**判定（历史已恢复正常不再标红），全部模式展示全部 20 个部位（含暂无数据）
- F-703：✅ 点击部位 → 右栏展示该部位指标列表（数值/单位/参考范围/异常标记，状态着色：正常绿、偏高红 ↑、偏低蓝 ↓、异常红）与历次检查记录
- F-704：✅ 无异常时模型正常色，可整体旋转/缩放
- F-705：⏳ **日常身体数据参与标注**：体重异常 → 全身高亮；血压异常 → 心脏高亮（与体检指标合并展示）
- F-706：✅ **LLM 严重度判定**：异常部位严重度由大模型判断（`{"severity":"severe|moderate|mild","reason":"…"}`），右栏展示「AI 判定：…」理由；LLM 抛异常/非法 JSON/非法取值 → 回退数量规则（≥3 严重 / 2 中度 / 1 轻度）；同部位同异常集 24h 进程内缓存（指纹 SHA256），重复请求不重复调用；无 API Key/模型不可用时自动回退

## 5. 身体部位 ↔ 指标映射（3D 标注用）

| body_part | 指标示例 |
|-----------|---------|
| heart（心脏） | 血压（收缩/舒张）、心率、心电图、总胆固醇、LDL |
| liver（肝脏） | ALT、AST、γ-GT、胆红素 |
| kidney（肾脏） | 肌酐、尿素氮、尿酸 |
| pancreas（胰腺） | 空腹血糖、糖化血红蛋白 |
| thyroid（甲状腺） | TSH、T3、T4 |
| bone（骨骼/关节） | 血钙、维生素D、骨密度 |
| blood（血液） | 血常规（白细胞/红细胞/血小板等） |
| whole_body（全身） | 体重异常（BMI/单次体重超范围） |

> body_part 取值在后端不做强校验（自由文本），前端映射表统一维护，避免录入受限。

1. AI 提取触发方式：**手动按钮**（详情页点「AI 提取」，不自动调 LLM）
